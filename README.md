# *ECSDI PROJECT*
### Platform of services/agents capable of managing all processes from a global e-commerce company (such as Amazon). Platform development includes other external agents necessary to manage all the elements that are part of a solution, such as clients, third-party sellers, transportation services or payment services.
#### To try the platform: 
1. Download the code located in /app
2. $ python -m venv .venv
3. $ pip install -r /requirements.txt
4. $ pip install Flask
5. $ .\ .venv\Scripts\activate
6. $ .\run.bat
7. Test the different functionalities by connecting to each route via the internet (the first one recommended is the client route, so the user can 'register')
#### All additional information about the project System Specifiaction, Architectural Design, Detailed Design, Ontology and extras is present in /docs.
